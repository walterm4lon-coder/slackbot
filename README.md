# walter Slack Bot

walter is a simple Slack bot created with Node.js and the Slack Bolt framework. He is my first ever JavaScript project too.

The bot currently includes four slash commands.

## Commands

### `/walter-joke`

Sends a random joke in the Slack channel.

### `/walter-poke`

Checks whether the bot is running and responds with "Pong" and a reaction time.

### `/walter-help`

Displays a list of all available walter bot commands and explains what they do.

### `/walter-catfact`

Sends a random fact about cats.

## Built With

- Node.js
- Slack Bolt
- dotenv
